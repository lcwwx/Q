# 千里江山 · 合卷

两卷实时山水的《千里江山》，合成一个可以直接打开的游戏：**卷一「人在画中游」收八印，卷二「云游青绿」再收七印，十五印合成一卷。**

> 在线试玩：部署到 GitHub Pages 后把这一行换成你的网址，例如 `https://<你的用户名>.github.io/<仓库名>/`

---

## 这是什么

- **卷一 · 人在画中游**：第一人称走进青绿长卷，沿石径缓行，读题跋、钤画印，收满 8 印；右上「录影」可以录一段第一视角影卷。
- **卷二 · 云游青绿**：另一片青绿山水，可以泛舟、燃灯、抚琴、听风，收 7 印；七印归一会展开全景。
- **合卷**：两卷进度合成 15 印的账本，右侧「卷」扣可以随时换卷；十五印齐落终章。
- **两个入口**：封面「入卷一」「入卷二」各走各的，只想玩一卷也行，进度分开记。

两卷都是纯程序化生成的三维山水（Three.js），没有图片、模型、音频等外部素材；建议戴耳机。

## 怎么玩

部署完成后直接打开网址即可。键盘鼠标：

| 场景 | 操作 |
| --- | --- |
| 移动 | `W A S D`，`Shift` 疾行 |
| 视角 | 鼠标（点击画面锁定指针，`Esc` 解锁） |
| 交互 | 走近朱印 / 物件，按提示键 |
| 面板 | 右侧竖排「卷」扣：换卷、合卷账本、归卷 |
| 说明 | 封面与卷内都有「展读说明」 |

需要较新的 Chrome / Edge，且开启 WebGL2。

## 部署到 GitHub Pages

### 方式一：网页上传

1. 新建一个 **Public** 仓库，名字随意，例如 `qianli-river`。
2. 进入仓库 → **Add file → Upload files**，把 `千里江山图` 文件夹里的**内容**（`index.html`、`shell/`、`ch1/`、`ch2/`、`.nojekyll`、`README.md`）拖进去上传。
   - 网页上传可能会忽略以点开头的 `.nojekyll`，没有它通常也能跑（本站不依赖 Jekyll 特性），介意的话用方式二。
3. 仓库 **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `main`、目录选 `/ (root)` → Save。
4. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。

### 方式二：命令行（推荐，能带上 `.nojekyll`）

在 `千里江山图` 文件夹里打开终端：

```bash
git init
git add .
git commit -m "千里江山 · 合卷"
git branch -M main
git remote add origin https://github.com/<你的用户名>/<仓库名>.git
git push -u origin main
```

推送后在仓库 **Settings → Pages** 里选 `main` / `/ (root)` 即可。

### 几点说明

- 本站所有资源都用**相对路径**，所以放在 `用户名.github.io/仓库名/` 这种子路径下也能正常跑。
- 根目录必须有 `index.html`（已就位）。
- 最大文件是 825KB 的 JS，远低于 GitHub 单文件 100MB 限制。
- `本地运行/` 只是给本机预览用的，部署时可以一并上传（不会被当成页面），也可以删掉。

## 本机预览（不联网）

双击 `本地运行/启动本机预览.bat`，会起一个 `127.0.0.1:8910` 的小服务并自动打开浏览器。

> 不要直接双击 `index.html`：浏览器在 `file://` 下不允许两卷同源加载，页面会提示改用启动器。

## 实现

- 两卷原本是两个独立的 Three.js 项目，构建产物里的 `/assets/`、`/fonts/` 绝对路径已改为相对路径，放进同一站点的 `/ch1/`、`/ch2/` 子路径。
- 外壳与两卷**同源**，所以能读取它们的印章集合（`window.__QIANLI__`）、在卷一结局面板里加「入云」按钮，并在指针锁定时自动解锁鼠标。
- 进度存在浏览器 `localStorage`：卷一 `qianli-river-first-person.seals.v1`，卷二 `qianli-river-save-v1`；封面据此显示每卷进度和「续卷」。
- 卷二原有的「云上共游 / WebRTC 房间」在本机没有后端，合卷版已隐藏入口。
